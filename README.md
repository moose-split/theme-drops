# theme-drops

Versioned Shopify theme packages for the store project, installable via the Admin API `src` field (which requires a plain public URL serving exact zip bytes - GitHub raw provides that).

## Contents
- `horizon-theme.zip` - Shopify's open-source Horizon theme (github.com/Shopify/horizon, main branch as of 2026-09-16), repacked with theme directories at the zip root as the Admin API expects.

No secrets, no store data. Theme code is Shopify's open source.
